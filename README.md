# GV8 Global Solutions

A Next.js landing page for GV8's proposed Ghana-to-UK export, storage, fulfilment and marketplace-launch service.

## Stage

**Commercial staging page.** The UK warehouse capacity is confirmed by the business, but product acceptance, customs treatment, marketplace eligibility, client contracts, pricing and service-level terms must be approved before public launch.

## Run locally

```bash
npm install
npm run dev
```

Then visit `http://localhost:3000`.
